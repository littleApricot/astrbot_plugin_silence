# 沉默工具

给 AstrBot 增加无参数的 `silence` 工具。模型可以直接选择沉默，也可以在发图、修改记忆或其他工具操作后结束当前轮，不再追加文字回复。

## 安装

在原 littleApricot 插件源中刷新，搜索“沉默工具”安装；后续可在插件管理中一键更新。

```text
https://raw.githubusercontent.com/littleApricot/astrbot_plugin_reply_gate/main/plugins.json
```

也可通过[仓库地址](https://github.com/littleApricot/astrbot_plugin_silence)安装。插件无需配置或额外 Key，当前模型须支持工具调用，并允许使用 `silence`。

## 使用和历史

| 工具 | 参数 | 效果 |
| --- | --- | --- |
| `silence` | 无 | 结束当前 Agent 轮次，保留工具调用和完成记录，不再调用模型生成收尾回复 |

模型决定无需回应时，可以直接调用 `silence`。如果已执行其他操作，先看实际工具结果，再决定继续处理、正常回复还是沉默。

`silence` 应当是最后一次、单独的工具调用，该次正文留空。它保留已经执行的操作和已经发送的内容；不会撤回先前的消息。下一条新消息仍正常进入机器人流程。

例如，群聊表情图库 v0.2.9 的 `meme_send` 成功返回发送结果后，模型可以调用 `silence`，这一轮便只发送图片。其他工具同样适用，彼此没有插件依赖。

开启 AstrBot 的“显示工具调用过程”时，平台可能显示工具过程提示；希望整轮无文字时，应关闭该显示设置。

## 验证

已通过 AstrBot 原生工具执行器、Agent 循环和历史保存函数，验证直接沉默，以及实际写入本地文件后再沉默：操作结果和工具历史保留，结束后不再请求模型或产生最终文字回复。验证使用隔离环境，模型调用选择由固定输入驱动。

线上模型何时选择沉默，以及 QQ 上的实际工具调用，需安装后在对应环境验证。
